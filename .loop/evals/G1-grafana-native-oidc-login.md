eval: G1-grafana-native-oidc-login

Grafana authenticates humans against Vault's `lab` OIDC provider through its
own generic OAuth client, with no proxy in front, and every SSO user lands as
an Editor. The local admin account survives as the break-glass path.

Row methods reflect what this environment can reach. The devcontainer can read
the cluster's public endpoints, but `terraform apply` and any browser login
are the operator's to run: applying identity-layer changes and taking the
Consul state lock are not safe unattended actions. Rows that need the deployed
state carry `verdict: pending-operator`. (An earlier draft of this paragraph
said the session token carried `default` only. Adversarial review found that
understated it, and the token was destroyed mid-review, so the point is moot;
see the amendment on the `terraform plan` row.)
