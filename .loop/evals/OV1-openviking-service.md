# Eval: OV1 OpenViking service

eval: OV1-openviking-service

**Definition of Done:** OpenViking runs on radxa from a derived image whose
base is pinned, stores vectors in the existing `openviking` Postgres database
through `ov-postgres`, stores blobs in the existing `openviking` MinIO bucket
on a static key, embeds and reranks through Bifrost against embark, and
authenticates browsers against Vault's `lab` OIDC provider through a dedicated
oauth2-proxy, with no `.tf` file added to either root.

**Gated on U7.** Every rerank row below requires Bifrost >= 2.0.0
(`depends_on = ["U7-upgrade-bifrost-2x"]`). Run against 1.6.7 they fail with
`400 Invalid request payload`, which is the dependency working, not a defect
in this ticket.

**On R15 and the labelled proxy:** §11 Q7 resolved `widen-surface` for the
static half and `declared-proxy` for the runtime half. The R15 row below
carries the label naming what its proxy does NOT measure. A future edit that
strips that label turns an honest partial score into a false green.
