eval: T5-tls-certificate-expiry-alert

**Definition of Done:** Prometheus records days-to-expiry for the certificate
the edge actually serves, an alert fires on that value below the chosen
threshold and delivers to the existing contact point, and the alert has been
observed firing rather than merely existing. Nothing else in the monitoring
stack changes behavior.

**The way this ticket fails while looking done:** the rule is present, parses,
provisions cleanly, and would never fire. That is worse than no alert, because
it buys confidence about precisely the failure it was built for. Rows 3 and 4
exist to make "it fires" a measured fact. The second failure mode is an alert
that cannot fire because its series is absent (row 5).
