# Nodes

One concept per physical device in the cluster, and how jobs are placed across them.

* [firebat, the manager](firebat.md) - firebat (192.168.2.30) is the only amd64 node and the single copy of every control-plane service: Consul server, Vault, Nomad server, the Tailscale route and the HAProxy edge, plus Postgres. Its CPU is fully reserved, so new jobs go elsewhere, and when it goes down the whole cluster loses its control plane and every lab name.
* [jetson-orin-nano, the GPU node](jetson-orin-nano.md) - The Jetson Orin Nano (192.168.2.46) is the only GPU, and it serves embark's embedding and rerank models from 7619 MB of memory the GPU and the OS share. Root Podman runs the NVIDIA runtime, the CUDA libraries are bind-mounted by path, memex is parked off it for lack of memory, and losing it stops every embedding in the cluster.
* [orangepi4a, the storage node](orangepi4a.md) - The Orange Pi 4A (192.168.2.29) holds MinIO and its 1 to 3.5 TiB volume, plus ov-dash in the room the retired phoenix job left. Memory is its limit, several jobs hardcode its address even where a Consul lookup exists, and losing it takes every bucket, so Loki and Tempo cannot flush and the registry cannot serve a blob.
* [Node placement](placement.md) - Five nodes on 192.168.2.0/24: firebat is the only amd64 host and runs every server, the four arm64 workers each carry a fixed set of jobs. Placement is by hostname constraint, host volume and literal IP, so moving a job touches four places and one of them is on the node.
* [radxa-dragon-q6a, the application node](radxa-dragon-q6a.md) - The Radxa Dragon Q6A (192.168.2.50) carries the application tier: Hermes, Bifrost, OpenViking, dash, registry-ui, driftwatch, Redis, NATS, both oauth2-proxy gates and the nightly backups. Several jobs reach each other over loopback and so cannot move alone, five host volumes hold the rest in place, and its memory was down to 598 MB free by September 2026.
* [ubuntu, the observability node](ubuntu.md) - The Raspberry Pi 4B (192.168.2.47), whose Nomad hostname is the generic ubuntu, runs Prometheus, Grafana, Loki, Tempo, the OCI registry and the nightly ACME renewal. Its address is the scrape source that most service firewall rules admit, so moving the monitoring stack means rewriting rules on every node, and losing it silences every alert.
