modelkits bar is the layer stack, drawn to scale · open a kit to read its card

Nothing here touches the weights. A cold walk reads the catalog, one tag list per repo, one HEAD per tag, then per distinct digest a manifest and its blobs. A warm one reads only the first three: a digest is content-addressed, so a stored card never needs re-reading. Both tags of every repo resolve to one digest, so each kit is walked and drawn once.

container images repos whose manifest is an OCI image rather than a ModelKit

An image row costs one blob where a ModelKit row costs two: its config blob carries the architecture and the build date, and there is no card to fetch. A multi-arch tag resolves to an index, which names no single architecture and carries no layers, so that row shows its digest and nothing invented.
